Post a concise RCA comment to the Linear ticket.

## Steps

Post one comment containing exactly:

1. Diagnosis summary.
2. Evidence reviewed (with identifiers).
3. Probable root cause.
4. Recommended fix.
5. Remediation status: not attempted, attempted with approval, or blocked waiting for approval.
6. Verification steps and current result.

## Output schema

Emit `rca_posted=true` with the Linear comment ID.
