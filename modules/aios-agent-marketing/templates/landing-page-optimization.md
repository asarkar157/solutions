Create and optimize product launch landing page.

## Steps

1. Design wireframe: hero with headline + subhead + CTA, feature grid (3-4 key capabilities), social proof section (logos + testimonial quote), pricing/plan comparison, FAQ accordion, bottom CTA,
2. Build page in CMS with mobile-responsive layout,
3. Set up A/B test variants: test headline, CTA copy, hero image,
4. Configure UTM parameter capture in hidden form fields,
5. Connect analytics: GA4 page_view event, Mixpanel track signup_started, HubSpot form submission,
6. Set up conversion goals in GA4 and heatmap tracking via Hotjar/FullStory,
7. Launch page at embargo lift and drive traffic from email, social, paid,
8. Review A/B test results after 500 conversions per variant — declare winner at 95% statistical significance.
