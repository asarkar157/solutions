# Onboarding

Pick **one step at a time**. Each page is short; you can stop and come back later.

| Step | What you will do | Time (approx.) |
|------|-------------------|----------------|
| [1 — Orientation]({% link onboarding/01-orientation.md %}) | Understand what this repo is and how you might use it. | ~3 min |
| [2 — Your machine]({% link onboarding/02-your-machine.md %}) | Install Terraform (and optionally OPA), clone the repo. | ~10 min |
| [3 — Run checks]({% link onboarding/03-run-checks.md %}) | Format checks, policy checks, optional **`tofu validate`** (or `terraform validate`). | ~10 min |
| [4 — Use a module]({% link onboarding/04-use-a-module.md %}) | Point Terraform at a module `source` and plan a minimal stack. | ~15 min |
| [5 — Go deeper]({% link onboarding/05-go-deeper.md %}) | CI, registry tokens, full example, architecture — when you need them. | reference |

[**Begin with step 1 →**]({% link onboarding/01-orientation.md %})
